# Sudoku Solver using Recursion and Backtracking

A Python program that solves any 9×9 Sudoku puzzle automatically using the Backtracking algorithm.

## How to Run
1. Install Python 3.x
2. Run the program:
   python sudoku_solver.py
3. Enter each row as 9 space-separated digits (use 0 for empty cells)

## Files
- sudoku_solver.py — Source code
- Sudoku_Solver_Report.docx — Project report
- Sudoku_Solver_Presentation.pptx — Presentation
